# Spaced Repetition Agent

An Anki-inspired learning assistant with animated terminal flashcards and concise SMS reviews graded by an LLM. The working product name is Recall.

## Project documents

- [Complete project plan](docs/PROJECT_PLAN.md): architecture, terminal and SMS flows, grading rules, data model, milestones, and acceptance checks.
- [Codex implementation instructions](docs/CODEX_BUILD_INSTRUCTIONS.md): starter prompt and milestone-sized follow-up prompts.

## Get started

Open this repository in Codex and use the starter prompt in the implementation instructions. It points to `docs/PROJECT_PLAN.md` and begins with the first incomplete milestone.

## Status

Planning documents are available. Application implementation has not started.
